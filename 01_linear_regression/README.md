# 案例一：极简线性回归数值拟合 (Linear Regression)

对应教程：《AI训练入门.md》第 1 ~ 6 章

---

## 1. 业务与数学背景
- **任务目标**：通过随机生成的模拟数据，让单层神经网络自动寻找隐藏的线性关系公式：
  $$y = 2x_1 + 3x_2 + 1$$
- **输入特征**：2 个连续浮点数 $(x_1, x_2)$
- **输出目标**：1 个连续预测值 $y$
- **损失函数**：均方误差损失（MSELoss）
- **优化算法**：随机梯度下降（SGD）

---

## 2. 目录文件结构
```text
01_linear_regression/
├── model.py      # 模型结构定义 (nn.Linear(2, 1))
├── train.py      # 训练脚本 (自动生成模拟数据、验证集监控、保存 best_model.pt)
├── test.py       # 离线批量测试脚本 (评估全新测试集的 MSE 误差与最大偏差点)
├── predict.py    # 单样本推理与交互式测试脚本
└── README.md     # 本说明文档
```

---

## 3. 运行指南

### 步骤一：训练模型
```bash
python train.py
```
模型将在 0.1 秒内完成 60 轮迭代训练，并在当前目录下生成最优权重快照 `best_model.pt`。

### 步骤二：批量评估
```bash
python test.py
```
脱离训练环境，评估全新 20 个测试样本的均方误差与最大绝对偏差。

### 步骤三：单样本推理预测
```bash
# 默认样例预测
python predict.py

# 命令行直接输入特征测试 (x1=10, x2=2)
python predict.py 10 2

# 命令行交互式输入测试
python predict.py -i
```

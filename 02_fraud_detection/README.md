# 案例二：智能风控交易二分类决策器 (Risk Classification)

对应教程：《AI训练入门.md》第 7 章

---

## 1. 业务与数学背景
- **任务目标**：从“算数值”跨越到“做决策”。根据两项核心风控指标，预测单笔金融交易是否属于疑似盗刷行为。
- **输入特征**：
  - $x_1$：交易金额相对于历史平均值的偏离倍数
  - $x_2$：本次交易与上次异地登录的时间间隔（小时）
- **输出标签**：
  - $y=0$：正常交易（放行）
  - $y=1$：疑似盗刷（拦截）
- **核心结构**：`nn.Linear(2, 1) + nn.Sigmoid()`（将任意实数分值平滑压缩至 $0 \sim 1$ 的概率值）
- **损失函数**：二元交叉熵损失（BCELoss）
- **优化算法**：随机梯度下降（SGD）

---

## 2. 目录文件结构
```text
02_fraud_detection/
├── model.py      # 模型结构定义 (RiskClassifier: Linear + Sigmoid)
├── train.py      # 训练脚本 (业务数据分布生成、val_loss 最优模型保存)
├── test.py       # 离线批量测试脚本 (评估全新测试集的二分类准确率 Accuracy)
├── predict.py    # 单笔交易推理与实时决策交互脚本
└── README.md     # 本说明文档
```

---

## 3. 运行指南

### 步骤一：训练模型
```bash
python train.py
```
训练 100 轮并在当前目录下保存最优模型权重 `best_model.pt`。

### 步骤二：批量测试
```bash
python test.py
```
在独立的测试集上评估分类准确率（通常达到 100%）。

### 步骤三：单笔交易推理决策
```bash
# 默认标杆用例测试
python predict.py

# 命令行直接输入特征 (金额偏离 8.5 倍, 异地间隔 0.2 小时)
python predict.py 8.5 0.2

# 交互式实时判定模式
python predict.py -i
```
